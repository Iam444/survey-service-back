# OTY Surveys [Backend]

> Бекенд-часть сервиса управления опросами, являющийся частью веб-приложение OTY — мультисервесного приложения для менеджмента проектов.

🔗 **[Ссылка на приложение](https://orgtool.ru)**

---

## Стек технологий
* **Основа:** Node.js, архитектура выстроена по DDD
* **Фреймворк:** Nest
* **СУБД:** Postgres SQL
* **ORM:** MikroORM



### Внутренняя библиотека
Приложение использует собственную библиотеку надъязыковых абстракций в формате "internal-usage" - 
является самостоятельным репозиторием, подгружается в проект отдельно,
собирается и предоставляет свою кодовую базу через линк с помощью "file:" в package.json основного приложения бека.

Библиотека предоставляет абстракии Entity и ValueObject, абстракции для разделения Error и Exception, 
монаду Result для более эффективной обработки ошибок и пр.

🔗 **[Библиотека lang-extensions](https://github.com/Iam444/lang-extensions)**

## Запуск на локальной машине

### 1. Клонирование основного репозитория
```bash
git clone https://github.com/Iam444/survey-service-back.git

# Переход в корень бека
cd survey-service-back
```

### 2. Подготовка внутренней библиотеки
```bash
# Переход в дииректорию внутренних библиотек
cd lib

# Переход клонирование репозитория библиотеки
git clone https://github.com/Iam444/lang-extensions.git

# Переход в корень библиотеки
cd lang-extensions

# Установка зависимостей и сборка библиотеки
yarn install
yarn build

# Возвращение в корень бека
cd ../..
```

### 3. Установка зависимостей
```bash
yarn install
```

### 4. Подготовка БД
В СУБД Postgres SQL необходимо предварительно создать новую БД и, при необходимости, настроить пользователя (или использовать дефолтного)


### 5. Настройка окружения
Необходимо создать файл `.env.development` в корне проекта и добавить ключи конфигов БД и ключ секрета для JWT:
```env
JWT_ACCESS_SECRET=<любой рандомный секрет>

DB_NAME=<название БД>
DB_HOST=localhost
DB_PORT=5432
DB_USER=<имя пользователя БД (postgres - по ум.)>
DB_PASSWORD=<пароль пользователя БД (root - по ум.)>
```

### 6. Запуск проекта в dev-режиме
```bash
yarn start
```
